* Introduction
This program is an image acquisition software mainly intended for cameras, by using the [[https://github.com/genicam/harvesters][Harvester]] package. Furthermore it is possible to use more generic cameras via OpenCV.

* Installation
Do yourself a favour and install [[https://github.com/astral-sh/uv][uv]]. Running this program is then as easy as going into the directory and executing:
#+begin_src
uv run __main__.py
#+end_src

* Configuration
Available cameras should be automatically detected on startup. GenTL Producers (*.cti files) will be detected in the path given by the environment variable GENICAM_GENTL64_PATH (analogous to [[https://github.com/AravisProject/aravis][aravis]]).
